# Versioning policy

- Package version follows PEP 440. `0.1.0a0` is published in documentation as
  `v0.1.0-alpha`.
- Output schema versions are independent of package versions.
- Calculation standard versions identify the engine-wide standard set.
- Method and convention identifiers are immutable once released. A changed
  formula, boundary rule, ayanamsa interpretation or tradition receives a new
  identifier.
- Migration notes are required for removed/renamed fields, unit changes,
  default changes and convention changes.
- Release tags and publication require explicit owner approval; this milestone
  creates no tag, push or public release.
