# Licensing strategy

This public repository is licensed under **AGPL-3.0-or-later**. Swiss
Ephemeris is dual-licensed: users may use it under the GNU AGPL or purchase
the Swiss Ephemeris Professional Licence.

SimplyJyotish deliberately uses the AGPL option here. The repository,
including modifications and code that directly uses Swiss Ephemeris, is
therefore public source code under a compatible AGPL licence.

Before putting Swiss Ephemeris into a proprietary or closed-source
SimplyJyotish website, app, server, or distributed software, the owner must
obtain and comply with the Swiss Ephemeris Professional Licence, or keep all
relevant source code publicly available under AGPL. This note is engineering
guidance, not legal advice; verify the current terms directly with Astrodienst
before commercial launch.

No paid ephemeris files, secrets, confidential data, or proprietary content
may be committed to this repository.
